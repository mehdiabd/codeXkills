# codeXkills

سه skill کوچک برای استفادهٔ اختیاری در Codex:

- `$brief` — پاسخ کوتاه، مستقیم و در عین حال کامل.
- `$farsi-rtl` — متن ترکیبی فارسی و انگلیسی با چیدمان خوانای راست‌به‌چپ، بدون ترجمهٔ اجباری اصطلاحات انگلیسی.
- `$minimal-code` — کمترین تغییر لازم و درست در کد، بدون بازآرایی نامرتبط.

در یک درخواست، نام skill را بنویسید؛ مثلاً: `$brief $minimal-code این باگ را رفع کن.` می‌توانید چند skill را با هم به‌کار ببرید.

Skillها در `.agents/skills/` هستند. برای استفاده در پروژه‌ای دیگر، پوشهٔ هر skill را در `.agents/skills/` آن پروژه کپی کنید.
